- **🎯 Impact:** CNN-based model achieved 93% top-line accuracy natively, while the hybrid VGG19 + SVM pipeline scaled to 99.5% (Lychee) and 99.2% (Radish) on high-dimensional vectors.

- **🌐 Deployment:** Gradio interface providing farmers real-time diagnosis.
